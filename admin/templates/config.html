通知设置

{{ $n := .NotifyConfig }}
手机即时通知设置

用于即时向手机发送通知信息。

由Bark提供的免费手机即时通知服务（仅苹果设备适用）。

邮件通知设置

邮件通知用于向评论者发送邮件回复通知。收到评论时也会向此邮箱（即管理员）发送通知。

其它设置

{{ $c := .OthersConfig }}
地理位置解析

用于自动把文章编写时的数值地理坐标转换成周边兴趣点名字列表以供候选。

详情查看高德地址官方文档：地理/逆地理编码-基础 API 文档-开发指南-Web服务 API | 高德地图API。

维护模式

{{ $mc := .MaintenanceConfig }}
自动部署新镜像

接收到 GitHub Actions 的推送通知后，守护进程会在后台自动更新镜像并重新部署系统。

详情请参看文档：https://github.com/用户名/项目名/settings/hooks。

备份设置

自动备份到 R2/S3

Cloudflare R2 的 Endpoint 形如 https://<account_id>.r2.cloudflarestorage.com，Region 通常填写 auto。

该配置会在服务启动时用于加密备份上传；变更后，已运行的备份任务通常需要重启服务才会生效。
